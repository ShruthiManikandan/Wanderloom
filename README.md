
# WanderLoom – Travel Website

WanderLoom is a simple and modern **travel website homepage** built using **HTML and CSS**. The project focuses on creating an original travel brand and an attractive user interface without copying existing travel websites.

## ✨ Features

* 🏠 Attractive travel homepage
* 🌍 Original WanderLoom travel brand
* 🖼️ Destination-focused visual design
* 📱 Clean and user-friendly layout
* 🎨 Custom styling using CSS
* 🔗 Navigation and call-to-action sections

## 🛠️ Technologies Used

* **HTML5** – For creating the structure of the webpage
* **CSS3** – For styling, layout, colors, and overall design

## 📂 Project Structure

```text
WanderLoom/
│
├── index.html
├── style.css
└── images/
```

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in any web browser.
4. Explore the WanderLoom homepage.

## 🎯 Project Objective

The goal of this project is to practice **HTML and CSS fundamentals** by designing and developing an original travel website homepage from scratch.
